## Короткий конспект

- **Цель занятия:** создать нарративный срез — минимальную историю, которая поддерживает геймплей.
- **Паттерн:** персонажи → конфликт → 3–5 этапов квеста → 1 сцена.
- **Результат:** GDD.md с нарративом + 5 шотов для визуализации (домашка).
- **Контроль прогресса:** 3 чекпойнта + peer-review.
- **Правило курса:** "не задокументировано — значит не сделано".

## Что сегодня в GDD.md

1. **Characters** — 3–5 персонажей (роль, цель, конфликт, voice tag)
2. **Conflict** — основной конфликт + ставки
3. **Quest Structure** — таблица 3–5 этапов (цель → препятствие → действие → изменение)
4. **Scene 01** — 2 варианта диалога + финальная правка
5. **Glossary & Style** — 5–8 правил + 10–15 терминов

## Словарь терминов занятия

- **Вертикальный срез нарратива** — минимальная история, которая поддерживает геймплей и будущие ассеты.
- **Этап квеста** — шаг в цепочке прогресса (цель + препятствие + действие + изменение состояния).
- **Сцена** — конкретный эпизод с местом/участниками/конфликтом, который ведёт к действию игрока.
- **Voice tag** — 3 маркера речи персонажа + 1 запрет.
- **Тональность** — эмоциональный и стилистический режим текста (3 прилагательных + правила).
- **Глоссарий** — список терминов мира/механик с едиными определениями.
- **Контроль галлюцинаций** — приёмы, которые уменьшают "выдумки" LLM: канон, формат, допущения.
- **Shot** — описание кадра для генерации изображения.

## Мини‑FAQ

1. **Нужно ли делать сложные ветки диалогов?**
   Нет: 1 выбор игрока, 2 ответа, затем схождение — достаточно для вертикального среза.

2. **Что важнее: красивый текст или связь с механикой?**
   Связь с механикой и состоянием игры. Красота вторична.

3. **Можно ли полностью доверять LLM "канону мира"?**
   Нет. Модель помогает генерировать варианты, но канон задаёте вы.

4. **Как понять, что тон "держится"?**
   Реплики узнаваемы по голосу, нет "скачков" регистра, выдержаны запреты.

5. **Если диалоги слишком длинные?**
   Режем: 1 мысль на реплику, убираем повторы, переносим лор в окружение/ассеты.

6. **Зачем глоссарий так рано?**
   Чтобы не ломать консистентность (имена/термины) и проще писать промпты на визуал.

7. **Что такое API "на пальцах"?**
   Это когда вы не "в чате", а отправляете модели структурированный запрос и получаете ответ — удобно для пачек реплик, но требует контроля качества.
