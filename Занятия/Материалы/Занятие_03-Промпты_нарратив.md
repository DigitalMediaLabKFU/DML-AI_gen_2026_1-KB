## Запрос #9 — Критика нарратива

```
Роль: ты — нарративный дизайнер-рецензент.

Задача: проанализируй нарратив и найди проблемы.

Нарратив:
[вставь: персонажи + конфликт + структура квеста + сцена]

Проверь:
1. Каждый этап квеста меняет состояние?
2. В сцене есть микро-конфликт?
3. Игроку ясно, что делать после диалога?
4. Тональность описывается 3 прилагательными?
5. Нет противоречий с каноном?

Выведи:
— 3 сильные стороны
— 3 проблемы
— 3 рекомендации по улучшению
```

---

## Рекомендации по использованию

1. **Лимит итераций:** используй до 6 запросов на весь нарративный срез
2. **Сначала черновик:** не пытайся получить идеальный результат с первого раза
3. **Финальная правка:** всегда редактируй "в человеческое" после LLM
4. **Сохраняй канон:** явно указывай, что нельзя менять, в каждом запросе
5. **Логируй:** записывай запрос → ответ → вывод в gdd-log.md
