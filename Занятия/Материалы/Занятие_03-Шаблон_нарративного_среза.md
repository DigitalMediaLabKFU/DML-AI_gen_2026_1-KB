
> **Цель документа:** заполнить нарративный срез GDD — персонажи, конфликт, квест, сцена, стиль.
> **Когда использовать:** на занятии 3 и для домашнего задания.

---

## 1) Персонажи (Characters)

### Обязательные поля для каждого персонажа (3–5 персонажей):

| Поле | Описание |
|------|---------|
| **Роль** | Кто этот персонаж в истории (протагонист/антагонист/NPC/союзник) |
| **Цель** | Чего персонаж хочет добиться |
| **Конфликт** | Что мешает персонажу (внутренний/внешний) |
| **Voice Tag** | 3 маркера речи + 1 запрет |

### Пример Voice Tag:

```
Голос: отрывистый,приказной,немногословный
Запрет: не использует метафоры и не говорит о прошлом
```

---

## 2) Конфликт (Conflict)

### Структура:

- **Основной конфликт** (1–2 предложения): что поставлено на кону
- **Ставки** (3–5 пунктов): что игрок потеряет/получит
- **Движущая сила**: почему конфликт нельзя игнорировать

### Пример:

```
Основной конфликт: Город захвачен, вы — единственный выживший курьер.
Ставки:
- Жизнь десятков заражённых зависит от лекарства
- Фракция "Стальные" контролирует единственный путь наружу
- Ваш транспорт — единственный, кто может пройти через блокаду
```

---

## 3) Структура квеста (3–5 этапов)

### Обязательные поля этапа:

| Поле                           | Описание                                                  |     |
| ------------------------------ | --------------------------------------------------------- | --- |
| **Цель этапа**                 | Что должен достичь игрок                                  |     |
| **Препятствие**                | Что мешает                                                |     |
| **Действие игрока (механика)** | Что игрок делает/нажимает/решает                          |     |
| **Изменение состояния**        | Что меняется после этапа (доступ/предмет/отношение/ флаг) |     |

### Пример таблицы:

| # | Цель | Препятствие | Действие игрока | Изменение состояния |
|---|------|-------------|-----------------|---------------------|
| 1 | Найти транспорт | Транспорт заблокирован | Осмотреть гараж, найти ключи | Открыт доступ к локации "Склад" |
| 2 | Добраться до склада | Охрана патрулирует | Пройти стелс-участок | Получен ключевой предмет "Посылка" |
| 3 | Забрать посылку | Секретный замок | Решить головоломку с кодами | Флаг "Посылка получена" |
| 4 | Вернуться к фракции | Засада на обратном пути | Выбрать: бой или бегство | Отношения с фракцией: +10 или -10 |

## 4) Сцена (Scene)

### Структура:

```
### Scene 01: [Название]

**Контекст:** (3 строки — где/кто/что на кону)

**Участники:** (2–3 персонажа)

**Ставка:** (что произойдёт, если игрок не выполнит)

**Вариант A — [тональность #1]:**
[Диалог]

**Вариант B — [тональность #2]:**
[Диалог]

**Final edit:**
[Отредактированная версия]

**Итог сцены:** [новый флаг/предмет/доступ/отношение]
```

### Ограничения:

- 8–14 реплик суммарно
- 1 выбор игрока (2 варианта)
- Каждая реплика несёт 1 функцию (угроза/обмен/инфо/действие)

---

## 5) Глоссарий и правила стиля (Glossary & Style)

### Правила стиля (5–8 правил):

```
1. Все персонажи обращаются к игроку на "ты"
2. Технические термины — только из глоссария
3. Нет прямых ругательств (заменять на [...]
4. Диалоги короткие: максимум 2 предложения
5. Описание локаций: 1–2 предложения, через запяту```

### Глоссарий (10–15 терминов):

| Термин | Определение |
|--------|-------------|
| Стальны́е | Фракция, контролирующая периметр |
| Заражённые | NPC, поражённые вирусом |
| Посылка | Ключевой предмет — лекарство |
| Блокада | Военный контроль на границе |
| Курьер | Роль игрока — доставщик |
| ... | ... |

---

## 6) Контроль галлюцинаций

### Правила:

1. **Канон не менять** — все факты мира фиксированы
2. **Допущения писать списком** — если данных нет, явно укажи
3. **Проверять связи** — текст → механика → состояние

### Чек-лист качества:

- [ ] Каждый этап квеста меняет состояние
- [ ] В сцене есть микро-конфликт
- [ ] Игроку ясно, что делать после диалога
- [ ] Тональность описывается 3 прилагательными
- [ ] Нет противоречий с каноном

---

## 7) Shot List (основа для визуализации)

### Структура шота:

```
### Shot ID: SH0X

**Purpose:** что доказывает (механика/конфликт/атмосфера)

**Scene:** где/кто/что происходит

**Camera:** крупность/ракурс

**Must-have:** 3–5 обязательных деталей

**Avoid:** 2–3 запрета

**UI overlay idea:** (если уместно)
```

### Связь с нарративом:

- Этап квеста → шот персонажа/локации
- Сцена → шот диалога/интерфейса
- Конфликт → шот атмосферный

---

## Рекомендации по заполнению

1. **Сначала персонажи + конфликт** (10 минут)
2. **Потом структура квеста** (15–20 минут)
3. **Затем 1 сцена** (15–20 минут)
4. **Глоссарий и стиль** (10 минут)
5. **Shot list** (домашка)

**Помни:** каждый этап квеста должен менять состояние. Если не меняет — это "сцена без игры".
