# Пример идеального репозитория (демо-проект)

Цель — показать “как выглядит чисто”: структура, навигация, selected, workflows, отчёты.

Демо-проект может быть выложен отдельным репозиторием/папкой преподавателя. Эта страница описывает стандарт, к которому стремимся.

---

## Как выглядит “идеально” (коротко)
- Открываешь `index.md` → за 1 минуту понятно: **что за игра**, где GDD, где selected, где workflows
- Selected — ≤20, подписано, без мусора
- Workflows — 3–5, понятные названия + notes
- `final.md` — “как воспроизвести” + provenance

## Что видно в `index.md` (минимум)
- 3–6 строк: elevator pitch + core loop
- 3 скрингена с подписями “что происходит”
- витрина selected (≤20)
- 3 ключевых workflow (что делает каждый)

## Что видно в `final.md`
- ссылки на GDD / selected / workflows / media
- краткая инструкция “как воспроизвести”
- provenance: инструменты, модели, референсы (если были)
