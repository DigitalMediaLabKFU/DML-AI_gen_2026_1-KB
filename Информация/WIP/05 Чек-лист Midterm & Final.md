# Чек-лист Midterm / Final

Цель — убрать неопределённость и ускорить проверку.  
Проверка ориентирована на **selected outputs** и читаемую навигацию.

---

## Общие требования (всегда)
- [ ] Репозиторий читаемый: нет “мусора”, названия понятные
- [ ] Есть `index.md` (или эквивалент) — быстрый вход
- [ ] GDD актуален (не оторван от ассетов)
- [ ] Есть воркфлоу `.json` для ключевых результатов
- [ ] В логах видно, что вы делали (Prompt Log / Workflow Notes)

---

## Midterm (контрольная точка)
**Должно быть в репо:**
- [ ] `midterm.md` (1–2 страницы)
- [ ] `outputs/selected/` — **≤12 изображений**
- [ ] `workflows/` — **2–3 ключевых workflow**
- [ ] GDD обновлён (минимум: core loop, стиль, список ассетов)

**Качество и воспроизводимость:**
- [ ] В каждом workflow понятны параметры (size/steps/CFG/seed‑стратегия)
- [ ] На selected есть подпись: “что это и зачем”
- [ ] Нет случайных “непонятных” файлов/версий

---

## Final (финальная защита)
**Должно быть в репо:**
- [ ] `index.md` (обязателен)
- [ ] `final.md` (обязателен)
- [ ] `outputs/selected/` — **≤20 изображений**
- [ ] `workflows/` — **3–5 ключевых workflow**
- [ ] GDD финальный/актуальный
- [ ] `media/` (или ссылки): audio/video/3d

**Обязательный состав selected (минимум):**
- [ ] **3 скрингена** (разные ситуации геймплея)
- [ ] 1 ключевой персонаж + 4 вариации
- [ ] 3–5 окружений/кадров мира
- [ ] 3–5 UI/иконок/элементов (в любой форме, допустим макет/оверлей)

**Воспроизводимость (достаточно для курса):**
- [ ] Есть workflow, которым получен ключевой результат
- [ ] Есть ключевые параметры + примечания по моделям/LoRA
- [ ] Если часть сделана локально — это отмечено в `final.md` (provenance)

---

## Быстрая самопроверка перед сдачей (2 минуты)
1) Открой `index.md` → всё видно и кликается?  
2) Есть ли 3 скрингена и подписи?  
3) Есть ли 3 ключевых workflow и понятно, что они делают?  
4) В `final.md` есть “как воспроизвести” и список использованных инструментов/моделей?
